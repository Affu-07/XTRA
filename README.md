# XTRA Construction Website

## About
A responsive construction website made using HTML, CSS, and JavaScript.

## Pages
- Home
- About
- Services
- FAQ
- My Account

## Technologies
- HTML
- CSS
- JavaScript
- Google Fonts
- Font Awesome

## Build
No build command is needed.

## Backend and API
This is a static front-end project. It has no backend, database, API, or environment variables. Forms and login are demo features only; they do not send or save data.

## Dependencies
Google Fonts and Font Awesome are loaded from CDNs. An internet connection is needed for these resources.

## Known Limitations
- Forms do not send information to a server.
- Login and password reset are not connected to a real account system.
- Search is not connected to a search service.
- Some links and buttons need to be tested before submission.

## Deployment
You can deploy this project using Netlify, Vercel, or GitHub Pages. Upload the project files and make sure `index.html` is in the published folder.
